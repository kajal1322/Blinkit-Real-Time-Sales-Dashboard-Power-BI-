# Blinkit Real-Time Sales Dashboard – Power BI

## 📊 Project Overview

An interactive Power BI dashboard developed to analyze Blinkit's grocery sales and business performance.

## 🎯 Key Features

- Total Sales, Average Sales, Number of Items & Average Rating KPIs
- Sales analysis by Item Type, Fat Content, Outlet Location & Establishment Year
- DAX-based calculations and analysis
- Interactive slicers and visualizations
- Business insights for data-driven decision-making

## 🛠️ Tools Used

- Power BI
- DAX
- Data Visualization
